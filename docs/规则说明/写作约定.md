# 写作与整理约定

## 文件怎么放

```text
docs/
├─ index.md              首页
├─ 规则说明/              长期约定，一个主题一个文件
├─ blog/
│  └─ posts/             随笔，一篇文章一个文件
└─ stylesheets/extra.css 想改字号、行宽就动这里
```

## 一篇文章的骨架

```markdown
---
date: 2026-11-13
categories:
  - 随笔
---

# 标题

一句话说清楚这篇在讲什么。

## 小节

正文。
```

- `date` 决定它在文章流里的位置，也是排序依据。
- `categories` 会变成分类页，写宽一点（`随笔`/`折腾`/`读书`），别一天一个新分类。

## 常用写法

| 想要 | 写这个 |
|---|---|
| 提示块 | `!!! note "标题"` 下一行缩四格 |
| 可折叠 | `??? note "点开看"` |
| 代码 | 三个反引号，后面接语言名 |
| 表格 | 竖线 `\|` 分隔 |
| 任务列表 | `- [ ] 待办` / `- [x] 做完 |

## 排版习惯

- 中英文之间空一格，读着舒服。
- 一行别写太长，Markdown 里手动换行不影响显示，但改起来方便。
- 标题层级最多到 `####`，再深就拆文件。
